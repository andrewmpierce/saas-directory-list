# SaaS directory list

A checked list of places to list a SaaS or AI product: review sites, launch platforms, directories and AI directories. Each entry has the submission URL, whether a free listing exists and what it requires, whether you need an account, and the date it was last checked.

<!-- COUNT:START -->42 directories · 33 loaded on the last check · updated 2026-11-16<!-- COUNT:END -->

It comes in three forms:

- **This page**, for people.
- **[`data/directories.json`](data/directories.json)** and **[`data/directories.csv`](data/directories.csv)**, for scripts and spreadsheets.
- **[`skills/saas-directory-submissions/SKILL.md`](skills/saas-directory-submissions/SKILL.md)**, a skill that tells an AI agent how to work through the list on a founder's behalf.

## How to read a row

| Column | Meaning |
|---|---|
| DR | Approximate Ahrefs Domain Rating when the terms were last reviewed. It drifts; treat it as a rough guide. |
| Free? | **Yes**: a free listing exists. **With badge**: free only if you put their badge or a link on your site. **No**: paid only. **Unknown**: not confirmed, or reports differ. |
| Paid | What the paid option is, where one was seen. Prices change often, so most rows describe the option and leave the number to the site. |
| Account | Whether you must sign in before you can submit. |
| Link | Link type as last reported: dofollow, nofollow or mixed. Confirm it on a live listing before relying on it. |
| Submit | The submission page. If a site has no direct one, this is the homepage and the note says so. |
| Checked | **Loaded**: the submission page answered a plain web request on that date. **Blocked**: the site refuses automated requests, so the row rests on the last manual review. |

◆ marks a directory run by this list's maintainer. See [Disclosure](#disclosure).

## What was checked, and what was not

- **Every submission URL was requested on the date in its row.** "Loaded" rows returned a page; where that page showed prices, a login, a badge step or a CAPTCHA, the note says so.
- **"Blocked" rows could not be read by a script.** Large sites often return 403 to anything that is not a browser. Those rows have a submission URL that other maintained lists also publish, and terms from a manual review in October 2026.
- **DR and link type come from that October 2026 review** for sites not run by the maintainer. They were not re-measured for this release.
- **"Unknown" means unknown.** Where the page did not settle a question, or two sources disagreed, the row says Unknown instead of guessing.
- Entries were dropped when the site no longer took submissions or had changed purpose.

If a row is wrong, [open a pull request or an issue](CONTRIBUTING.md). Corrections with a date are the most useful thing you can send.

## For AI agents

The data file is the source of truth; this page is generated from it.

- Raw data: `https://raw.githubusercontent.com/andrewmpierce/saas-directory-list/main/data/directories.json`
- Skill: [`skills/saas-directory-submissions/SKILL.md`](skills/saas-directory-submissions/SKILL.md)

The skill covers the order to try things in (a site's own `/llms.txt` or API first, then the form), which fields to fill, when to stop and hand back to a person (logins, CAPTCHAs, payment, terms), and how to report what happened.

## Disclosure

I run eight of the directories here: TheSaaSDir, TheAIToolsDir, SaaSLineup, TheDevToolsDir, TheMicroSaaSDir, TheDevToolsList, IndieLineup and TheDevToolsIndex. They are marked ◆, use the same columns as every other row, and are sorted by DR like the rest. Their free listings require a badge, which the Free? column says.

## Updating the list

```
python3 scripts/check_links.py   # request every submission URL and print the result
python3 scripts/build.py         # rebuild this page's tables and the CSV from the JSON
```

Edit `data/directories.json`, then run `build.py`. Do not edit the tables by hand.
